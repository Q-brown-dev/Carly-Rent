# 🚗 CorlyRent – Car Rental Website

CorlyRent is a modern, responsive car rental website built to deliver a smooth, stylish, and user-friendly vehicle rental experience. The project focuses on clean UI design, engaging visuals, and intuitive navigation suitable for car rental businesses.

---

## 🌐 Live Preview

(GitHub Pages / Netlify / Vercel)

---

## 📌 About the Project

CorlyRent was designed to showcase luxury and standard vehicles in a professional way.  
It includes a visually appealing hero section, gallery display, pricing layout, and contact page to help users easily explore and rent cars.

This project demonstrates modern frontend development practices and UI design skills.

---

## ✨ Features

- 🚘 Animated hero carousel
- 📱 Fully responsive design (mobile, tablet & desktop)
- 🎨 Clean and modern UI
- 🖼️ Gallery section for cars
- 💲 Pricing section
- 📩 Contact page
- 🧭 Smooth navigation menu
- ⚡ Optimized layout and performance

---

## 🗂️ Pages Included

- **Home** – Hero section with call-to-action
- **About** – Brand overview and mission
- **Gallery** – Car showcase
- **Pricing** – Rental plans and pricing
- **Contact** – Contact form and details
